# OmKiran Bhakti — website

Hindi-first devotional website for the OmKiran Bhakti YouTube channel: traditional aarti/chalisa lyrics with plain-Hindi meanings, bhajans by deity (real channel videos), Navratri 2026 page and an online jaap mala.

Live: https://omkiranbhakti.github.io/  ·  YouTube: https://www.youtube.com/@OmKiranBhakti

## How it works
- Pages are plain static HTML generated by `src/build.py` (no dependencies, Python 3).
- Lyrics live in `src/lyrics.py`; videos, pages and FAQs live in `src/build.py`.
- `python3 src/build.py` rewrites every page, `sitemap.xml`, `robots.txt` and `llms.txt`.
- Pushing to `main` deploys through GitHub Actions (`.github/workflows/pages.yml`) to GitHub Pages — free.

## Content rules
- Only traditional/public-domain texts (aartis, chalisas, stotras, mantras, folk/traditional geet) or OmKiran Bhakti's own lyrics.
- Never add full lyrics of songs by a known modern lyricist or label.
- Meanings are original writing. Dates (festivals) must be checked against a panchang before publishing.
- Every video ID must come from the real channel — no invented links.

## SEO
- One H1, unique title/description, self canonical, Open Graph, JSON-LD (Organization, WebSite, WebPage, BreadcrumbList, CreativeWork, ItemList, FAQPage, Event, WebApplication).
- Answer-first opening paragraph on every page (for Google and AI answers).
- YouTube embeds load only on click (fast pages).
