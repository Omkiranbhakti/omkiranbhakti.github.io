# OmKiran Bhakti Website

A responsive Hindi devotional landing page for the OmKiran Bhakti YouTube channel.

- Static HTML with inline responsive CSS and JavaScript
- SEO metadata, canonical URL, and MusicGroup structured data
- Devotional categories: Shiva, Mata Rani, Hanuman Chalisa, Krishna, Ganesh, Aarti/Chalisa/Mantra
- Playlist links for bhajan jukebox and Hindu EDM
- Sitemap and robots.txt
