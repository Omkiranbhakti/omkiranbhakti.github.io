# Rochak / bahas wale topics — for ALL social media (X, Quora Space, Pinterest later)

Added 2026-11-14 (owner asked for interesting, debate and "controversy" style posts on all platforms).

Rules (apply on every platform):
- Allowed: scripture debates (Mahabharat, Ramayan, Puran), temple/tradition practices people argue about, surprising facts about temples — numbers ONLY with a named source and year, written in the post ("स्रोत: …").
- Never: religion vs religion, politics/parties/leaders, caste, any community, named living people (no kathavachak fees, no gurus' income, no celebrity gossip), unverified money claims, mocking any belief. Respectful tone, always end with a question to the reader.
- Before posting a money/number fact, re-check it with a web search; if the newer figure differs, use the newer one and its source. If it can't be confirmed, skip that topic.
- Each topic is used once per platform. Mark per platform: "X: [x] (date) URL", "Quora: [x] (date) URL".

How each platform uses this list:
- X: Monday, Wednesday, Friday — one item, in place of the evergreen post (short version below, under ~130 Hindi characters plus link).
- Quora Space "पौराणिक कथा सागर": Tuesday, Thursday, Saturday — the daily Space post is the next item from this list instead of seo/quora-mythology.md (long version: hook question, 4–6 short paragraphs with the facts/kathas from the notes, the source line, "आपकी क्या राय है? कमेंट में लिखें।", last line "ऐसी ही रोचक पौराणिक बातें और त्योहारों की सही जानकारी: omkiranbhakti.com"). Other days stay mythology stories.
- Pinterest: only once a pin image exists in img/pins/ (not yet).
